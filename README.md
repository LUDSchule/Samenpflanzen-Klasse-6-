# Samenpflanzen - Stationen fuer Klasse 6

Vier interaktive Stationen zum Thema Samenpflanzen, verschluesselt.
Zum Oeffnen wird das Passwort gebraucht, das die Lehrkraft nennt.

Die Inhalte stammen aus lizenziertem Unterrichtsmaterial und sind
deshalb verschluesselt abgelegt (AES-256, Schluessel aus dem Passwort
ueber PBKDF2-SHA256). Sie sind ausschliesslich fuer den Unterricht
in der eigenen Lerngruppe bestimmt.
